# Permafrost JS SDK

The Permafrost Software Development Kit is an API wrapper around the Permafrost
API. It contains all the resources you could need to create your oAuth app.

## Getting started

Install the package from
[NPM](https://www.npmjs.com/package/@snowflake-software/permafrost-js) using the
package manager of your choice:

```shell
npm i @snowflake-software/permafrost-js
pnpm i @snowflake-software/permafrost-js
bun i @snowflake-software/permafrost-js
yarn add @snowflake-software/permafrost-js
```
